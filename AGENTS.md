
# AGENTS.md

## Project Rules

1. Understand the existing project structure before modifying code.
2. Follow the existing coding style and architecture.
3. Reuse existing components and functions.
4. Do not rewrite existing functionality.
5. Avoid unnecessary dependencies.
6. Modify only the files required for the requested feature.
7. Only support staff can change a ticket's status. 
8. An employee sees only their own tickets; support staff see all tickets. 
9. A Closed ticket can't be edited, but comments can still be added. 
10. Title and description can't be empty. 

## Testing Rules

1. Add or update relevant tests.
2. Run available tests after implementation.
3. Do not delete existing tests to make them pass.
4. Report test failures honestly.

## Safety and Ownership

1. Explain the implementation plan before coding.
2. Do not modify unrelated files.
3. Show all modified files and the Git diff.
4. Never commit or push without explicit approval.
5. Wait for human review before considering changes complete.
